# Problem
If you enjoy RPGs, you often create multiple characters with different classes, abilities, and equipment. Keeping track of all those characters in one place can be difficult. Players need a simple way to organize their characters and track their stats, inventory, and equipment.

# Initial requirements
R1: Users can create a new character with a name and class.
R2: Each character has health, strength, defense, and level.
R3: Users can see a list of all characters they have created.
R4: Users can edit a character's details.
R5: Users can delete a character.
R6: Each character has an inventory that can store items.
R7: Users can add items to and remove items from a character's inventory.
